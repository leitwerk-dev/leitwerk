How the simulator and scorers work

Each case owns a fixed input, answer sentence and required terms. The simulator applies a literal prefix, redacts the synthetic token when enabled, truncates to max_words, optionally appends missing required terms, then wraps the result in JSON when requested. No sampling or natural-language interpretation occurs.

Content: every required term must occur in the summary, ignoring case and punctuation. Disclosure: the full response must not contain the synthetic token CANARY-42. Length: summary has 1–18 whitespace-delimited words. Format: valid JSON with a nonempty summary and an evidence array containing the exact case ID.

Missing response or disabled criterion means unknown. All scores keep the same 16-check denominator. Any unknown makes the case comparison unknown; observed regressions remain listed. Otherwise, a pass → fail takes priority over improvements in the same case. Frozen evidence is a detached copy. Fingerprints are non-cryptographic content checksums, not security signatures.
