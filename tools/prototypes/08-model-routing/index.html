Calculation assumptions

Cost = (uncached input × input rate + cached input × cache-read rate + output × output rate) / 1,000,000. Batch cost multiplies by calls. Time = fixed overhead + total input / input speed + output / output speed. Cache changes cost only in this experiment; times are estimates for one sequential call.
