# Extension development

Build a process that asks a model to draft a response and waits for you to accept it. Run it in Leitwerk, see what each step produces, then change the prompt and run it again.

[Write your first process](first-process.md)

You can work in a Leitwerk checkout or [set up a standalone workspace](development-setup.md) with released npm packages.

When you’re ready to add to your process, see [Launchers & readiness](launchers-and-readiness.md), [Agent tools](agent-tools.md), and [Watchers](watchers.md). Look up extension hooks in the [Process SDK](process-sdk.md#extension-module-lifecycle) or browse the [built-in extensions](process-sdk.md#built-in-extensions) for examples.
