# Using Leitwerk

Someone sends you a proposed bug fix to review. Open the process in Leitwerk and read its **Chronicle**, the timeline of that task.

<div class="process-chronicle" markdown>

1. **Bug report**<br>
   “The CSV export skips the last row.”
2. **AI’s plan**<br>
   “Include the last row and add a test for a one-row export.”
3. **Your review**<br>
   Approve the plan or ask for a change. The process waits here.

</div>

[Find a process that needs your review](operate-processes.md#what-to-do-when-a-process-pauses)

## Run your first process

Try **Single Prompt** to see a request and its answer in your own Chronicle.

1. Open **Start a process** and choose **Single Prompt**.
2. Enter this **Prompt**.

    > Write a three-item checklist for getting ready for a team meeting.

3. Choose **Start now**, then **Run Prompt**.
4. When the process shows **Completed**, read the checklist in the Chronicle.

To find it again, search **All processes** for `team meeting`.

If prompted, choose a model under **Model setup**. If **Single Prompt** is missing, ask your administrator to enable it.
