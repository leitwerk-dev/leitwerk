# Manage skills

A skill gives the AI instructions for a task. For example, a review skill can tell the AI which checks to make when reading a change.

## Install a skill

1. Open **Skills** in the sidebar and choose **Available remotely**.
2. Search for the skill or narrow the list by repository. Open the skill and read **Instructions** to see what it asks the AI to do.
3. Click **Install skill**. Find the skill under **Installed**.

If a published skill or update is missing, open **Repositories** and click **Refresh all** to check the configured sources.

## Use a skill on a new run

Open **Start a process** and choose a workflow. If its launch form offers **Skills**, select the installed skills you want before submitting. **Bundled** skills are available automatically to every AI step.

## Update or remove a skill

Open the skill under **Installed**. If **Update skill** appears, select it to make the newer version available to future launches. To remove a skill installed from a repository, click **Remove**, then **Confirm removal**. Existing processes and schedules keep the versions they already use.

For skills managed by an extension or the installation's configuration, check **Managed by** and ask the person who manages Leitwerk to make the change.
